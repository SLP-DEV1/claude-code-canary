# Code of Conduct

Claude Code Canary is a technical open-source project. Contributions, bug reports, compatibility data and criticism are welcome when they help make the project more reliable.

## Expected behavior

- Be respectful and discuss the work rather than the person.
- Give reproducible technical context when challenging a result or design decision.
- Assume good faith, but accept corrections when evidence shows a mistake.
- Keep issue and pull-request discussions relevant to Canary.
- Respect privacy. Remove secrets, private prompts, tokens, personal data and confidential project details from logs and artifacts.
- Disclose security vulnerabilities through the private process in [SECURITY.md](SECURITY.md), not in a public issue.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, doxxing, deliberate publication of private data, spam, impersonation, malicious payloads disguised as reproductions, or repeated disruption after a maintainer asks for a discussion to stop are not acceptable.

## Enforcement

Maintainers may edit, hide, lock or remove content that violates these rules and may restrict participation when necessary to protect contributors or the project. Enforcement should be proportionate to the behavior and documented where doing so is safe.

For abuse involving GitHub accounts or content where public discussion would create additional harm, use GitHub's reporting tools rather than posting personal details in this repository.
